# 001

Android electric-guitar learning assistant. V1.0.0 grows first-position knowledge one
coordinate at a time, separates required note sets from the real note universe, and keeps
three physical training regions. Note, solfege, and scale-degree mapping progresses from
single symbols through pairs, sequences, missing items, patterns, and chord-tone sets. A
shared clean-tone player adds actual fretboard pitches and optional audio prompts without
microphone access or performance recognition.
