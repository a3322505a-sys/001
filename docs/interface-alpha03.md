# alpha03 首页与训练页精简

落实用户确认的首页合并、信息上移、减少常驻文字和沉浸训练反馈。

- 首页四个入口：吉他入门、指板训练、进阶应用、知识树。吉他入门收纳认识吉他、基础认识和读谱入门；课程 ID、前置条件、掌握记录保持不变。
- 紧凑卡片保留当前模块的开始/继续入口，取消每类大面积进度块和首页常驻结束总结。常规手机与默认字号按单屏设计；系统大字号仍可滚动，避免内容被截断。
- 训练页只保留主要题目与必要答题内容。移除课程副标题、重复操作口令和底部提示栏；教学说明、提示、错误反馈集中在题目下方有边框的卡片内，普通正确回答用已有图形标记反馈。
- TAB 题面和音名选项也位于上部。纠正后的下一题放在顶部；听音、提示、结束练习放进右上角菜单，左上角返回可暂停。
- 训练时隐藏状态栏与导航栏，边缘滑动可临时唤出；返回其他页面恢复。保留摄像头挖孔避让，切换应用回来重新应用训练模式。
- 包名和长期签名继续沿用，数据库 schema 1 未变。版本 2.0.0-alpha03（20）。

验证沿用已有 CI 的单元测试、Debug/Release 构建与 API 35 覆盖升级检查。真机单屏布局、菜单使用和沉浸手势效果待用户试用；不新增截图系统或额外验收门槛。
