# 音阶与五种指型：v0.3 施工记录

参考图的彩色边界彼此重叠，不是五个互斥的品位区间。例如 mi/sol 共用 5弦3品 C3；sol/la 共用 3弦5品 C4；la/si 共用 1弦8品 C5；si/re 共用 4弦10品 C4。边缘的 F（2弦6品）、B（3弦4品）和 13品 C/F 保留原图位置；不能按旧 0–12 品区间裁掉 re 形，也不能用名字字母反推形状。图未给出逐音左右手指法，App 只记录弦品和音高，不把框线当成手指动作。

五型模板由 `MajorScalePatterns.kt` 唯一保存；`ScalePatternLessons.kt` 从它生成主音、一八度及完整音域的上下行、C–E–G、调内三度、三音模进、换起点回主音和相邻连接。关系组的撤提示检查会换顺序或起点。双名称、预览和练习共享同一节点进度。页面显示一次一型；训练使用原任务、判题和档案，提示后的独立作答另记。旧音位成绩不会变成指型掌握。当前 C 大调的 mi 型可直接预览和练习；推荐在 p03 后转向首型与局部关系，不要求 mapping、完整音程或 p09 通关。

五型中可切到 A 自然小调视角：相同音位以 A 为主音，C 为小三度；对应 A–C–E 关系任务单独留证据。si / CAGED E 是可移动形态，移到 G 大调为 2–5 品、F 大调为 12–15 品；练习由同一 C 大调模板平移并重新计算实际音高、调内级数和 F♯／B♭ 拼写，不移动开放弦。五线谱短句改为明确的级进、三度和回主音材料，原 TAB 与八段短谱保留。

档案恢复校验对坐标序列以标准调弦换算实际音高，再与关系音列逐项比较；关系音列不吻合的快照仍拒绝。旧课程 ID、Room schema 和原有进度不变。

本轮未改 Room schema、包名、签名或旧课程 ID。新节点的历史为空时按未学处理；暂停任务沿用原快照。APK 可见版本预留 `2.0.0-alpha31` / versionCode 48。构建、CI、签名包和真机结果分别在 PR 记录，不能互相代替。
