# 项目01：alpha30 指板视口与训练布局修复

## 范围与根因

仅处理 a3322505a-sys/001 当前 learning 入口。基线 main 7d4f22e（PR #67，alpha29/46）。

已证实：TeachingGeometry 只按高度生成模型宽度；TeachingFretboard 未使用可用宽度限制比例；BoardTaskLayout 在横屏又只分配约56%宽度给指板。完整琴头占位与逐题横移叠加，导致琴头巨大、指板离屏、只能看到少数品格。

## 需求—规则—验收

|需求|实现规则|验收口径|
|指板完整居中|按可见品位范围与可用宽高等比适配，板高上限192dp|首末品与六根弦都在视口内|
|缩放适宜|仅保留琴枕旁的空弦琴头片段，移除额外完整琴头占位|低把位不再由三格撑满半屏|
|选项空间清晰|题目/谱例在上、指板居中、选项在下，纠错区预留高度|七音名常规横屏单行；反馈变化不推移选项|
|切题稳定|取消逐题自动横移；相同范围与窗口共用几何|播放/失败/静音/纠错/保存六状态答案边界一致|
|小屏大字|短窗口整体纵向滚动；普通窗口长题干及说明区可滚动|内容可以到达，极端大字不承诺一屏全部显示|
