# R1：区域折叠、四套主题与节点状态

依据《吉他App未来规划方案_20260906_0456.md》，本批交付 R1。版本为 2.0.0-alpha04（21），从 main `c1b06f6` 建立 `feature/r1-regions-themes`，通过 PR 与现有 Android CI 交付。完整未来方案的 R2–R7 仍为后续批次；P01–P03 已有用户真机确认，不重新列作未验收课程。

## 当前行为

- 指板训练展示低把位 0–4 品（P01–P09）、中把位 5–8 品、全指板 0–12 品三个紧凑区域。初次进入全部折叠，一次只展开一个；从节点详情或训练返回时保留展开区域与滚动位置。
- 低把位分母固定包含当前全部九个课程节点，例如 P01–P03 掌握后显示 3/9。未实现区域显示规划中，不能开始训练；已实现但先修不足的节点显示未解锁，可以查看详情。
- 首页继续学习入口保留；区域只用于展示，课程 ID、先修、推荐顺序与学习证据均沿用 Curriculum。
- 节点状态在列表、知识树和详情共用：掌握为绿底浅字加 ✓，可学习为蓝色，未解锁为灰色加锁和文字，规划中为中性虚线。当前节点增加边框及文字；需复习保持掌握底色并加琥珀提示，不重新锁住后继。
- 设置 → 外观 → 配色主题可选清爽青白、暖纸森林、午夜蓝、石墨紫。使用方案色值；当前首页、课程、树、历史、详情、设置、训练答题、Material 弹窗及系统栏图标跟随主题。教学指板的木纹、金属琴弦和已有教学标记保留物理外观。

## 档案兼容

在现有 LearnerState JSON 快照追加字符串 `themeId`，默认 clear。不增建存储系统，不改 Room schema 1；主题和其他状态共用原事务保存路径，保存成功才更新屏幕。

- 旧快照和旧备份缺字段：读取为默认主题，学员身份、任务、进度、回答和会话继续保留。
- 未知主题字符串：档案仍可读取，界面回退清爽青白；不因此重建学员或清空数据。
- 主题随原备份导出、恢复和覆盖升级保存。恢复旧备份会恢复该备份的学习数据，并使用默认主题。
- 保存异常：原事务回滚，原数据及原主题继续有效，可按既有错误提示重试。

## 验证与交付边界

沿用仓库 Android CI，不添加新 gate。原 Room 测试扩展主题关闭重开、事务失败回滚/重试、缺字段快照/备份及未知 ID；原 API 35 覆盖安装检查增加主题保留断言。补充区域分母、规划锁定与需复习不重新锁课的定向检查。

CI 的覆盖安装检查使用本次代码递增版本的 Debug 包；旧版本缺少 themeId 的兼容由旧格式档案测试覆盖，不宣称已经在用户手机覆盖安装。正式 APK 使用原发布证书和版本 21，记录 CI 构建 source-sha 与 main 对应关系。

构建和自动检查不等于真机视觉验收。交付后重点看：三个区域默认首屏可见；单区域展开和返回位置；四主题在知识树、详情、设置、训练及弹窗的可读性；大字号可滚动；重启/覆盖安装后原进度和主题保留。
