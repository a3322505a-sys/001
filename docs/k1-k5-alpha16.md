# K1–K5 · alpha16

本批接续 U1/U2（alpha13）、U3（alpha14）和 P1（alpha15）。原 R1–R7、接口分工、Room schema 1 和掌握阈值复用；新增目标使用 extension 技能标识与 curriculumVersion 8，历史证据不重写。

| 批次 | 本批新增 |
| --- | --- |
| K1 | 升降还原及拼写、主动构建八度与三/五度、多参照高低方向听辨 |
| K2 | 局部 A 小调五声音阶、四分/二分/八分及休止、拍格起音顺序、2–4 音问答 |
| K3 | 大调级数检索与随机起点、大小调主音比较、强力和弦移动、根三五构建、按实际低音识别转位、不同起音琶音 |
| K4 | 同音高跨相邻区域、共同音与最近路线、C 调调内和弦与短进行、多个合法和弦落点、多参照旋律/和声音程、3–5 音记忆及单独节奏听辨 |
| K5 | 8 小节作品（两句、一次换把、G/C 落点）、G/F 调及正确拼写、C/D/G 大调五声音阶、保存原作后按实际音高移至 G 调 |

具体直接前置见 FurtherLessons.nodes。局部五声音阶和作品不要求完成全部 12 品。换调改写必须存在已完成原作；不会用模板替代“自己的作品”。创作判断音集合、音序、区域、时值与结尾条件，允许多个答案，不打审美分。

T01–T04 的清晰单音、交替拨弦/消音、击勾滑、推揉弦以相关课程详情内实琴练习及自评承载。自评保存到同一档案，不换算成屏幕答题掌握证据；不宣称已验证演奏能力。

测试覆盖每题合法答案、等价音高/错误八度、调性拼写、转位实际低音、创作保存与原作移调、音高和节奏分开留证据、25 个新课程独立过关与序列化恢复。沿用现有 CI 的构建、升级保留和音频设备检查。额外在同一模拟器输出固定显示契约图片，供人工检查，不增加截图通过门槛。

真人试用仍需验证指板可点性、吉他听感、短谱读奏体验。P1 保持 8 段，不据自动化结果扩展曲库；K6（七和弦/调式/和声小调/更长作品）未开工。
