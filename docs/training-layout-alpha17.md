# alpha17 — 训练页布局与区域入口

基线 main 161e24d（alpha16/33）；版本 alpha17/34。

## 布局

- 顶部保留标题、返回、下一题和菜单。宽屏下方信息区左侧为谱面/操作，右侧为说明/纠错；各区独立滚动，文字不再挤在指板上沿。
- 音位题、和弦、TAB/五线谱、关系题和短谱试点沿用同一分区原则。窄屏/大字号回流；指板在提示出现、纠错和题型切换时保持相同区域高度。
- 短音列按音数决定宽度，三音不会拉满整屏；带时值谱保留完整小节和时值比例。超出宽度可浏览。
- 和弦 O/X 移到弦枕前对应琴弦中央。按钮和图例可换行，选项不挤成一条长行。

## 入口与恢复

U3 的“先恢复所有旧题，再进入区域”会让区域按钮打开 TAB/和弦等不相关练习。本批改为立即进入区域，暂停上下文随原档案保存；低中全各自恢复原题。摸底只统计当前区域会话，跨区域练习不串计数。

仅增加缺省为空的 JSON 暂停上下文字段，Room 表/版本、历史证据、课程门槛及签名不变。原专项及 suspendedLesson 一同保留，短谱计时和素材曝光不重置。恢复时校验暂停上下文，失败保留原档案。

## 验证

补充区域切换、旧专项/部分答题/短谱恢复、序列化和事务失败保护。扩展既有人工截图场景，覆盖三音 TAB、和弦提示/纠错、选项及读谱试点，不新增 CI gate。

本地环境缺少 Gradle 发行包且下载受网络限制，验证使用仓库原 Android CI；构建/截图结果随 PR 更新。真实设备触点、字号和听感需用户验收。
